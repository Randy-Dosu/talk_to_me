# Nkommo — a private AI journal and mood tracker for Ghana

> *nkommo* (Twi): conversation.

**Mental health is stigmatised in Ghana. Many people suffer silently. Nkommo is a private, accessible tool that reads the
weather in a person's writing and surfaces distress early — without asking them to disclose it to anyone.**

This repository contains a working web application, a deterministic on-device analysis engine, a clinical screening
layer (PHQ-9 / GAD-7), an evaluation harness with a hand-labelled corpus, and the research and staging plan behind the
build. It also contains a Python/FastAPI + Hugging Face reference path for the production ML service, which is **not**
serving this demo.

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
```

Other scripts:

```bash
npm run build      # typecheck + production build
npm test           # 96 tests: engine, geo ranking, HF adapter, prompts/prompter, chat flows, route smoke
npm run eval       # regenerates src/engine/eval/report.json (the model card numbers)
npm run typecheck
```

First visit: one signup page collects everything the app needs — alias, language, an optional trusted contact, and the
"not a diagnosis" acknowledgement. The chat then asks for nothing else; every other page is reference material. You can
skip signup, or load fictional sample data from the empty chat to see the patterns populated.

## The stack

- **React 19 + TypeScript + Vite** — app shell, routing, state.
- **Tailwind CSS v4** — design tokens in `src/index.css` (warm paper, forest, clay, gold; Fraunces + Inter).
- **Recharts** — mood trend chart.
- **Custom engine in `src/engine`** — no runtime model download, no network, deterministic and explainable.
- **Vitest + Testing Library + jsdom** — 96 tests including the signup, chat, voice, location-ranking, HF-adapter, prompter-scheduling and safety flows.
- **Python reference path in `ml/`** — FastAPI service and a RoBERTa/GoEmotions fine-tuning script for the production
  model, kept separate so it never pretends to be what the demo runs.

Why the demo does not ship a transformer: the production model needs Hugging Face weights, a serving path and — more
importantly — Ghanaian annotated data. A lexicon plus rules can be audited line by line, runs offline on a cheap phone,
and is the right baseline to beat. See `docs/ROADMAP.md` Stage 9.

## The reading, in one paragraph

Text is normalised (contractions, Ghanaian spellings such as `k3k3 → small`, emoji, elongation), scored against a
lexicon with VADER-style rules (negation flips by −0.74 within three tokens, intensifiers scale, “but” re-weights the
clause, shouting and `!` add intensity), then combined with eight clinical marker groups into a 0–100 distress index and
a 0–100 mood score. A **separate** safety pass scans for risk language in three tiers, suppresses protective or
figurative phrasing at sentence level, keeps third-party risk (“my friend wants to die”) out of the writer's own tier,
and escalates on composites such as intent plus planning language. Every contribution is surfaced to the writer as a
quoted phrase, and the writer can override the band.

Measured on a 30-case held-out split: risk-tier accuracy 90%, urgent recall 100%, high-risk recall 100%, mood-band
agreement 77% (MAE 8.8). Across all 82 cases: 91.5% risk accuracy and 100% urgent recall. The blind split that was run once mid-build scored much worse at first — 33% urgent recall —
and that first-run result is published on the model card and in `docs/RESEARCH.md`. In-house numbers are a pipeline
check, not clinical validation.

## Safety

- This is **not** a medical device, diagnosis, or emergency service.
- It cannot contact anyone, and it does not run in the background.
- Ghana resources used throughout: **0800 678 678** (Mental Health Authority, free, 24/7) and **112** (emergency).
- Risk language always surfaces helplines, including inside the composer before an entry is saved.
- A “no safety signal” reading is explicitly described as *not* an all-clear.
- Numbers were verified against public sources in November 2026 and must be re-verified before any real deployment.

If you are in danger now, call **112** or **0800 678 678**. Do not rely on software for an emergency.
